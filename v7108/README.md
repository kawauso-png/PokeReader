# v7.10.8d ROM不一致の診断版

v7.10.8の実機ログ5本で、予測開始前のERROR 00000005を確認した。読み取ったROM全体のFNVは57D31952、解析用ROMの期待値は6C177283。原因を判定するため、この版はY＋↓の直後、ゲームを停止したままROMを照合する。

不一致の場合、`rank7108_rom_<ID>.bin`（2 MiB）と同名の`.txt`をSDの`/luma/plugins/pokereader/traces/`へ保存し、`S7108D ROM CHECK STOP`で止まる。`ROM DUMP SAVED - RETURN SD`なら成功。↑を押さず、ゲームを終了して電源を切り、SDをMacへ戻してこの2ファイルを解析する。再探索・イベント実行は不要。

`DIAGNOSTIC NOT SAVED`の場合は保存に失敗しているので画面のエラー番号とSD上にできたファイルを確認する。ROM不一致を許可する変更は入れていない。ROMが一致する場合だけ従来の実験的探索に進む。

以下はROM一致時の従来の探索動作。

日本語版VCクリスタルのスイクン直前で使う。色違い成功率の向上は実機未検証。予測順位を使って入力候補を選ぶ試験モード。

1. 今までと同じスイクン直前の位置・停止状態・RNG画面で **Y＋↓** を押し、すべてのボタンを離す。
2. `SEARCHING` / `CHECKING CANDIDATE` の間は待つ。B操作は不要。
3. **`TRY xxxx RANK n`** と `HOLD UP UNTIL PAUSED` が出たら、**↑だけを押し続ける**。
4. 再び停止したら↑を離す。従来のExact2・M14でイベントを進め、最終DVとCSVを記録する。
5. `SHINY - CATCH IT!` ならSTARTで再開して捕獲。それ以外は従来どおりVCをリセットして次の試行へ。

`RANK` は予測候補内の順位。成功確率や色確定を意味しない。上位128位以内の色候補があり、2つ以上の参照経路が支持する場合に止まる。既存モデルの範囲外や候補の弱い開始状態では、↑を通さずに次の開始地点を探す。

候補待ちの時間は未測定。2〜3分ほど待っても候補が出ない場合は **SELECTで検索を一時停止**し、下記scanログを回収すれば、実際に出現した開始条件を解析できる。SELECTは↑待ちの準備が完了する前の検索中に使える。

## 保存するデータ

すべて `/luma/plugins/pokereader/traces/` に保存。

- `rank7108_scan_....csv`：検査した入力地点のRNG・音楽計算値・採用/棄却。↑を押さなくても収集する。
- `rank7108_....csv`：採用時の事前予測。**物理↑を受け付ける前に保存・flush・closeを完了**する。
- `celebi_trace_....csv`：これまでと同じ実測ログ。事前予測IDと、凍結保存した候補スコア内での実測DV順位も追記する。

試行後はこの3種類をまとめて回収する。予測と実測の対応付けは `analyze_ranked_trials.py` で自動化した。結果からモデルを更新するのは解析側の作業であり、実機がその場で未検証の学習を行う仕様ではない。

## エラー時

`PREDICTION STOPPED` / `ERROR xxxxxxxx` の場合は↑を押さず、表示コードとscanログを回収する。主なコード：

- `00000001`：入力地点がneutral3・指定PRE条件と一致しない。
- `00000002`〜`00000004`：実機内メモリの読み取り位置を検証できない。
- `00000005`：実機ROM全体の照合値が解析ROMと異なる。
- `00000101`〜`00000105`：音楽処理のコピー上で未対応の読み取り・命令等を検出。
- `000002xx`：SD記録に失敗。事前記録なしで↑を通すことはしない。

現在の試作はPRE AP4=2A35、SP4=2A40、neutral3、物理↑ Exact2、M14に限定。ROMは実機にロードされたものを読み取り、ローカルな作業用メモリ上で音楽計算する。ROM・RAM・RNG・DIV・DVへの書き込み、合成↑入力は追加していない。

## 検証

9件の実ログで、C版の音楽計算時間・448バイトの音楽状態・候補数・実測DV順位がPython版と一致。候補スコアの差は浮動小数点の丸め範囲。ホスト上では、早押し↑、候補棄却、予測失敗、事前ログ失敗で入力準備に進まないことを検証した。

3DS用ビルドと自動検証を通した後で配置する。実際の3DSでの最初の起動・検索・試行はユーザーによる確認が必要。
